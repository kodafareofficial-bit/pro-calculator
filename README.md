# ماشین‌حساب پرو

ماشین‌حساب مدرن و حرفه‌ای برای موبایل، ساخته‌شده با **Flutter**؛ کاملاً **راست‌چین**، با طراحی تمیز، تم روشن/تیره و حالت علمی.

**توسعه‌دهنده:** امیرعلی فراهانی

---

## ✨ امکانات

- **طراحی مدرن و راست‌چین (RTL)** با فونت وزیرمتن و ارقام فارسی (قابل خاموش‌کردن)
- **تم روشن، تیره و خودکار** (هماهنگ با سیستم)
- **پیش‌نمایش زنده‌ی نتیجه** هنگام تایپ، پیش از زدن `=`
- **ماشین‌حساب علمی:** `sin cos tan ln log √ xʸ ! π e` با انتخاب درجه/رادیان
- **درصد هوشمند:** `۲۰۰ + ۱۰٪` برابر ۲۲۰ است (مثل ماشین‌حساب‌های واقعی)
- **ضرب ضمنی** (`۲π`، `۳(۴+۱)`) و **بستن خودکار پرانتز**
- **تاریخچه‌ی ذخیره‌شده:** ضربه = استفاده از نتیجه، نگه‌داشتن = ویرایش عبارت، کشیدن = حذف
- **دقت بالا:** حذف خطای ممیز شناور (`۰٫۱ + ۰٫۲ = ۰٫۳`) و نمایش علمی اعداد خیلی بزرگ/کوچک
- **کپی نتیجه** با نگه‌داشتن روی نمایشگر؛ **حذف با کشیدن** روی نمایشگر
- لرزش هنگام لمس، انیمیشن دکمه‌ها، پشتیبانی از **دسترس‌پذیری** (Semantics فارسی)
- ذخیره‌ی خودکار تنظیمات و تاریخچه

## 🧱 ساختار پروژه

```
lib/
├── main.dart                  نقطه‌ی ورود، تم و محلی‌سازی (fa-IR)
├── core/                      پالت رنگ، تم، قالب‌بندی اعداد، اطلاعات برنامه
├── logic/
│   ├── calculator_engine.dart     موتور محاسبه (parser بازگشتی، بدون وابستگی به UI)
│   ├── calculator_controller.dart وضعیت ورودی، پیش‌نمایش، تاریخچه
│   └── settings_controller.dart   تنظیمات ماندگار
└── ui/                        صفحه‌ها و ویجت‌ها (نمایشگر، صفحه‌کلید، شیت‌ها)
test/                          تست‌های واحد موتور و قالب‌بندی
scripts/setup.sh               راه‌اندازی اولیه‌ی پلتفرم‌ها
```

منطق محاسبه کاملاً از رابط کاربری جداست و با تست‌های واحد پوشش داده شده است.

## 🚀 اجرا

پیش‌نیاز: [Flutter](https://docs.flutter.dev/get-started/install) نسخه‌ی پایدار (Dart ‏3.6 به بالا).

```bash
git clone <آدرس-این-مخزن>
cd pro-calculator

bash scripts/setup.sh      # فقط بار اول: ساخت android/ios و تنظیم نام برنامه
flutter pub get
flutter run                # اجرا روی دستگاه یا شبیه‌ساز
```

> روی ویندوز، `scripts/setup.sh` را در Git Bash اجرا کنید، یا دستور
> `flutter create . --org ir.farahani --project-name pro_calculator --platforms=android,ios`
> را دستی بزنید و در `AndroidManifest.xml` مجوز `INTERNET` را اضافه کنید.

## 📦 ساخت نسخه‌ی نصبی

```bash
flutter build apk --release        # خروجی: build/app/outputs/flutter-apk/app-release.apk
flutter build appbundle --release  # برای Google Play
```

این مخزن یک workflow گیت‌هاب (`.github/workflows/build-apk.yml`) دارد که با هر push روی `main`
فایل APK را می‌سازد؛ از تب **Actions ← Build APK ← Artifacts** می‌توانید دانلودش کنید.

> **انتشار در فروشگاه‌ها:** برای انتشار، یک keystore اختصاصی بسازید و امضای release را
> طبق [مستندات Flutter](https://docs.flutter.dev/deployment/android#sign-the-app) تنظیم کنید
> (نسخه‌ی پیش‌فرض با کلید debug امضا می‌شود). آیکن لانچر پیش‌فرض Flutter است و باید با آیکن
> برند جایگزین شود (مثلاً با `flutter_launcher_icons`).
